## File structure

- Root: public HTML pages (`index.html`, `404.html`, `secret.html`, `privacy.html`).
- `assets/css/`: site stylesheets.
- `assets/js/`: site scripts and ES modules.
- `assets/images/`: branding, screenshots and certificate previews.
- `assets/media/`: project videos and additional media.
- `assets/documents/`: downloadable certificates.
- `assets/vendor/`: self-hosted libraries, fonts, icons and licenses. Keep third-party package folders intact so internal URLs continue to work.

Serve the repository root when previewing locally. HTML and runtime media URLs point to `/assets/`; module imports and stylesheet font URLs are relative to their own files. Keep the public HTML pages at the root so page URLs stay stable.

# Dimitris Mourchoutas — portfolio

A static portfolio for GitHub Pages. No build step is required.

## Local preview

Serve this directory over HTTP (for example, `python -m http.server 4174`) and open `http://localhost:4174`. The floating gallery uses JavaScript modules; opening `index.html` directly as a file retains standard project cards instead.

## Privacy and consent

- `assets/js/privacy.js` is the only Analytics loader. The main, secret, 404, and privacy pages never request Google Analytics before an explicit opt-in. Both acceptance and rejection are remembered in `portfolio-cookie-consent` local storage for 180 days. Unavailable or invalid storage defaults to analytics off.
- The footer's Cookie settings control reopens the same equal-choice panel. Withdrawal disables the tag, removes accessible `_ga`, `_ga_*`, `_gid`, and `_gat*` cookies, and reloads the page to remove loaded listeners. Choices synchronize across tabs and are rechecked on back/forward-cache restoration.
- Google signals and advertising-personalization signals are disabled. Analytics cookies request a fixed 180-day lifetime. These options do not replace checking the Google Analytics account's own advertising/linking and data-sharing settings.
- `privacy.html` explains the site operator, contact, purposes, legal bases, hosting/CDN providers, optional analytics, browser storage, email, transfers, and visitor rights. `assets/css/privacy.css` styles the shared consent panel and legal pages without external dependencies.
- **Analytics retention confirmed by the owner on 21 October 2026:** Event data: 14 months; user data: 2 months; reset on new user activity: enabled. These account settings are reflected in `privacy.html` and are separate from cookie expiry and standard aggregate report retention. Update the notice if the account settings, providers, or processing change.

## Optimized publication

Run `npm ci` once, then `npm run build`. Publish the contents of `dist/`, not the repository root, to use minified CSS/JS and versioned filenames. Source files remain in `assets/`; never edit generated files. Each build recreates only the verified `dist/` output directory. Vendor licenses are preserved. Hosting handles transfer compression and cache headers; this build does not change provider settings or deploy anything.

About and Contact enhancements preload within 1000px of the viewport. Gallery geometry initializes at startup to keep section height stable. The Skills module and GPU buffers warm during idle time after the intro, with an approaching-section fallback and asynchronous shader compilation. Project demos preload on pointer/focus and initialize only once per project; direct links wait for the selected demo before opening. The source site also benefits from these runtime changes and the smaller loader logo. Use the root for development and serve `dist/` for release checks.

GitHub Pages deployment: .github/workflows/pages.yml runs on pushes to main (or manually from Actions). Set Settings > Pages > Source to GitHub Actions. The workflow installs locked dependencies, builds dist, uploads only that folder, and deploys after a successful build. dist and node_modules stay untracked. Include all moved assets and package-lock.json in the commit. Actual hosted deployment is verified after pushing.
